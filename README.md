## features:

- **ghost mode** — read messages, watch stories and type without sending status
- **bypass** — copy, forward and save from restricted chats (`noforwards`), screenshots everywhere (`FLAG_SECURE` disabled)
- **adblock** — hides sponsored channel messages
- **raw tl/json** — copy full MTProto message payload from the context menu
